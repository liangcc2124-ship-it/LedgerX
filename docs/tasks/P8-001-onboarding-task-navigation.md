# P8-001：首次使用引导与任务型导航

- 状态：待排期（当前本机版本可使用；此任务不是启动门槛）
- 类型：产品流程与跨层 UI
- 依赖：账本初始化 API 已稳定；本机主流程已通过真实浏览器验证
- 影响：Vue 应用壳/初始化页、profile 创建流程、少量 presentation map；不改变财务计算

## 用户结果

首次用户无需理解“用户空间、账户启用日、AST”等内部概念，即可完成：选择账本起始日期 → 填写期初余额 → 确认默认账户 → 创建第一笔记录 → 在总览看到结果。中途退出后能从已提交步骤恢复，不重复写入。

## 交互设计

1. `setupState=PENDING` 时应用壳显示专用引导，不挂载 Records/Metrics/Dashboard；浏览器刷新从服务端状态恢复。
2. 引导只保留三个业务步骤：账本从哪天开始、当时有多少钱、记录第一笔收支。高级分类/账户设置以可选入口呈现。
3. 初始化提交成功后刷新 capability/context epoch，再进入第一笔记录；不得由前端假设完成。
4. 已完成用户不再自动看到引导，可从设置查看起始日期和账户信息；改变起始日期遵守 P7-002 的已有记录约束。
5. 主导航按任务频率排序：财务总览、收支记录、分类与账户、指标与公式、用户空间、设置。技术版本和 READY 状态移入设置/诊断，主工作区只保留简洁连接异常提示。
6. Dashboard 空数据提供“添加第一笔记录”主行动；记录页缺分类/账户时提供可点击修复路径，而不是仅禁用按钮。

## 验收

- 全新 profile 仅用键盘可完成初始化和第一笔记录，关闭所有弹窗后焦点回到触发点。
- 在初始化提交前退出：重开仍为 PENDING 且零部分写入；提交成功后断电式重开：状态为 COMPLETED 且默认账户只存在一份。
- 无账户、无可用分类、初始化 API 400/409/423/503、请求超时和操作结果未知均有明确恢复路径。
- 320px 只要求引导和弹窗可关闭/可滚动；1024×768 与 1440×900 无溢出、遮挡或不可达按钮。
- 全流程使用真实浏览器→Java 同源 REST→SQLite 验证一次，mock 仅用于异常 UI 回归。

## 禁止事项

不得把初始化状态写入 localStorage；不得自动创建虚假的第一笔记录；不得在 Vue 计算期初余额或日期合法性；不得为引导引入全局状态框架，继续使用现有 appContext 和请求 composable。
