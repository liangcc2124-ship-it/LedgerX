# P7-003：本机网页版的构建与使用基线

- 状态：本机自用基线已完成；不是正式发行版门禁
- 日期：2026-09-24
- 规模：小型单用户工具。只要求在个人 Windows 电脑上持续运行、保护账本，并让关键操作结果可核对。
- 依赖：P7-004 本机浏览器运行时、P7-002 账本初始化规则

## 目标

用一条简单、可重复理解的路径构建和启动网页版：Vue 页面由 Java 同源服务提供，Java 是 SQLite 唯一写者。无需 Electron、桌面壳、Vite 代理、安装器或发布审计体系。

## 日常路径

首次准备或修改代码后，在项目根目录执行：

```powershell
cd frontend
npm ci
npm test
cd ..
.\scripts\build-web.ps1
.\scripts\start-local.ps1
```

平时使用时只需运行 `scripts/start-local.ps1`，再用浏览器打开终端显示的网址；按 `Ctrl+C` 停止本机服务。前端使用锁文件安装依赖，支持 Vite 要求的 Node.js 版本；Java 使用 Java 11。Maven Wrapper 和项目缓存负责取得/复用 Maven，不要求维护者手工切换缓存。

## 持续需要的检查

- Java 测试在构建时运行；前端配置、单元、浏览器 UI 测试通过 `npm test` 运行。
- 跨层改动至少用隔离账本完成一次真实浏览器 → Java → SQLite 闭环；不得拿 mock 或开发代理代替真实运行路径。
- 涉及迁移时验证旧数据可读取、迁移后可保存并重载；测试数据与个人账本隔离。
- 服务只绑定 `127.0.0.1`；浏览器会话、CSRF、Host/Origin 校验和单写者锁不可为省事而绕过。
- 手工备份前先停止 Java，再复制完整数据目录；关闭浏览器标签不等于停止服务。

## 不作为个人使用门槛

不要求特定厂商/补丁号的 JDK、双 Maven 缓存比对、SBOM、干净 Git checkout、安装包/离线分享包、20,000 条数据压测，或 P3–P6 所有历史任务先全部通过。性能检查在真实数据或使用中出现卡顿时再按问题定位；其它未实现能力单独排期，不阻止当前已验证的记账主流程。

## 完成标准

本机 Java 服务能提供网页和 API；用户可完成初始化、创建/编辑/回收/恢复记录，刷新和重启后数据仍从 SQLite 读取；服务退出后端口和数据写锁释放。任何未实际验证的产品能力仍标注未验证，不把本机可运行描述成分享包或正式发布。
