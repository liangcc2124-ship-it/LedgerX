# P9-003：数据可迁移导出与恢复验收（按需）

- 状态：BLOCKED（等待 P9-001、P9-002）
- 类型：数据可携带性、兼容性和最终验收
- 依赖：备份/恢复实现 PASS

## 目标

确保用户不被专有文件锁住，并证明备份在另一隔离安装中可恢复。首版提供只读 CSV 导出，不在同一任务实现通用 CSV 导入，避免未定义映射污染账本。

## CSV 导出合同

1. Java 根据当前 profile 和显式筛选生成 UTF-8 BOM CSV；金额为十进制字符串，日期 ISO-8601，状态/类型使用稳定代码并附中文显示列。
2. 导出列固定版本并写入伴随 manifest：exportVersion、应用/schema 版本、时区、筛选、行数和 SHA-256。备注按 RFC 4180 转义，防止换行/引号破坏结构。
3. 防公式注入：以 `= + - @` 开头的文本字段按文档化规则安全转义；金额和日期仍保持数据语义。
4. Java 写入受控 `Exports/<profile-id>/`，API 返回 export ID；浏览器使用受控下载响应取得文件，不接受 Vue 指定任意本机路径。

## 恢复门禁

- format 当前版本、上一支持版本、坏 ZIP、错 hash、跨 profile、未知高版本、磁盘满和中断矩阵全部通过。
- 在第二个隔离数据根恢复后，记录/账户/公式/布局数量、关键黄金值和数据 revision 一致。
- 创建备份、恢复和 CSV 导出在 20k 记录样本上不阻塞 renderer；记录耗时和峰值磁盘占用。
- 用户文档包含备份位置、未加密声明、恢复流程、兼容版本、CSV 列定义和故障处理。

## 非目标与升级

CSV 导入、旧 JSON 导入、云同步和跨 profile 合并另立需求与映射规范；不得把导出文件直接回灌数据库。只有本门禁通过后，设置页才能把“手工复制数据目录”升级为“应用内备份/恢复”。
