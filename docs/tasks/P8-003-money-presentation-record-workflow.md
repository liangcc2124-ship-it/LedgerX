# P8-003：统一金额呈现与高频记账工作流

- 状态：BLOCKED（等待 P8-001、P8-002）
- 类型：前端呈现、交互效率与一致性
- 依赖：初始化和记录查询合同稳定
- 影响：共享 presentation formatter、Records/Dashboard/Metric 页面、浏览器与原生验收；不改变数据库金额正值不变量

## 用户结果

用户无需先阅读记录类型即可判断资金方向，并能快速重复录入相似账目。全产品金额格式、隐私状态和可访问表达一致。

## 呈现合同

1. 数据库/API 金额继续保持正值字符串；UI 根据 recordType 和账户 balanceSide 显示方向，不修改服务端事实。
2. CNY 默认显示 `+¥12,000.00` 或 `−¥2,800.00`；Dashboard、记录、账户和指标复用一个纯展示 formatter。精度、负号、千分位和不可计算状态必须一致。
3. 收入/支出使用符号、文字和颜色共同表达；屏幕阅读器 accessible name 包含“收入/支出、金额、币种”，不能只靠红绿。
4. “复制此记录”创建新草稿，复制类型/分类/账户/备注，日期默认今天，id/revision/幂等键必须重新生成；不会静默提交。
5. 保存、编辑、删除、恢复后保留 P8-002 当前筛选和滚动锚点；目标记录不再匹配时给出说明，而不是突然跳页。
6. 表单选择类型后只展示适用分类；没有匹配分类时提供进入分类管理的明确入口。

## 验收

- ASSET/LIABILITY × 收入/两类支出的列表文字、符号与账户余额方向正确。
- `0.01`、大额、千分位、隐藏值、EMPTY/NOT_COMPUTABLE 和长数字不溢出。
- 复制记录不会复用 entity ID、revision 或 idempotency key；取消零写入。
- 键盘完成新增、复制、编辑、删除确认和恢复；焦点、滚动和筛选状态可预测。
- 1440/1024 桌面和 320 弹窗检查通过；console 无相关错误；真实原生链路至少覆盖复制后保存与重开。

## 禁止事项

不得改变 API 金额为负数来适配显示；不得在每个页面复制格式化逻辑；不得加入仅 hover 可见的关键操作；不得用自动提交换取“快速记账”。
