- 日期：2026-09-24

## 当前状态

P7-004 浏览器运行时、P7-002 账本初始化与 P7-003 本机使用基线均已验证。普通使用不依赖 Electron、Node 或 Vite；启动 Java 服务后在本机浏览器记账即可。P7-003 不是面向分享、安装器或正式发行版的门禁。

主流程已通过隔离账本验证：初始化、记录创建/编辑/回收/恢复、余额核对、刷新和服务重启后重载。P9-001 现已补齐应用内手动备份：可以创建当前用户空间快照、查看历史、深度校验和下载；测试使用真实浏览器 → Java → SQLite，且没有使用个人默认数据。备份未加密；恢复、自动备份和自动清理仍未实现。

## 长期保持的做法

- 不绕过 loopback、浏览器会话、CSRF 和 SQLite 单写者保护。
- 改数据库迁移时验证旧账本可打开、写入和重载；只用隔离副本测试。
- 改跨层功能时走一次真实浏览器 → Java → SQLite；局部 UI mock 不能替代它。
- 只对改动相关的层次测试。没有真实卡顿或实际大数据需要时，不跑 20,000 条压力测试。
- 不引入云同步、多人账号、微服务、发布审计、SBOM 或安装器，除非产品范围真的改变。
