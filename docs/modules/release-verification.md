# 本机网页版构建与验证约定

- 状态：当前个人使用方式
- 边界：Vue 3、Java 11、SQLite 的本机网页运行，不涉及公开部署或安装包
- 任务：[P7-003 本机使用基线](../tasks/P7-003-reproducible-release-gate.md)

## 日常使用

构建前端：在 `frontend/` 执行 `npm ci` 准备依赖；修改代码后执行 `npm test`。在项目根目录运行 `scripts/build-web.ps1`，它会构建 Vue 页面并运行 Java 验证。构建完成后运行 `scripts/start-local.ps1`，浏览器通过 Java 同源访问页面和 `/api/v1`。

正常记账只需启动已有构建，不需要 Node、npm、Vite 或 Electron。服务仅绑定 `127.0.0.1`；停止时在服务终端按 `Ctrl+C`。手工备份或测试迁移前先停止服务，并只对隔离副本操作。

## 每类改动的检查

- 纯 UI 修改：运行相关页面回归；视情况运行 `npm test`。
- Java 业务或 API 修改：构建会运行 Java 测试；核对结果和错误行为。
- 跨层或持久化修改：用隔离账本走真实浏览器 → Java → SQLite 的新建、读取/重载与相关状态变化。
- 数据迁移：使用隔离旧数据副本，验证可打开、可保存、可再次读取。

检查范围随改动变化，不要求每次构建都重做无关性能测试。没有实际卡顿或数据量增长时，不要求 20,000 条记录压测。

## 不包含

没有面向多台电脑的部署、安装器、离线分享包、捆绑 JRE、软件物料清单（SBOM）或正式发行决定。若未来明确需要分享或公开发布，再新增相应需求并设计验证，不让这些尚未需要的流程进入个人日常使用。
