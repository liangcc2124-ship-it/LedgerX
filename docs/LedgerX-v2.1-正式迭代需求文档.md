## 1. 版本定位

### 1.1 迭代主题

数据可带走、可恢复、可清空；记录可纠错；财务状态可按日、周、月、年回顾；风险可按用户自己的规则预警。

### 1.2 当前问题

v2.0 已经完成指标总览、自定义指标、手动记录、本地存储、金额隐私、基础分析、备份恢复和 CSS 皮肤，但仍存在以下关键缺口：

1. 备份文件没有版本、时间、摘要和完整性校验，恢复前也没有预览。
2. 用户无法在应用内清空数据或恢复出厂状态。
3. 记录只能新增和删除，无法修改或撤销误删。
4. 固定成本、可变成本和净现金流主要展示累计值，缺少周期口径。
5. 财务分析没有日报、周报、月报和年报。
6. 报告没有趋势、结构、比较等可视化图表。
7. 用户不能为现金、成本、Runway 等指标设置自己的预警规则。
8. 财务依赖度依靠分类文字包含“父母”判断，口径不可靠。
9. 账本损坏时会保留损坏副本，但缺少用户可理解的恢复流程。

### 1.3 版本目标

v2.1 必须实现：

- 完整、可验证、向后兼容的数据备份与恢复。
- 应用内清空账本、恢复出厂和保护快照。
- 记录编辑、软删除、恢复和短时撤销。
- 统一的统计周期与指标口径。
- 日报、周报、月报和年报。
- 趋势、结构、比较和现金变动可视化。
- 用户自定义财务预警规则与预警中心。
- 更可靠的收入来源和财务依赖度计算。

### 1.4 非目标

v2.1 不实现：

- 云同步、登录账号、多人协作或手机端。
- 自动读取银行、微信、支付宝或券商数据。
- 自动支付、转账、投资操作或消费建议。
- 多币种折算和实时汇率。
- 复杂自定义指标公式编辑器。
- 嵌套 AND/OR 预警规则树。
- 完整预算系统和周期计划系统。
- 企业会计、税务申报和法定财务报表。
- 强制后台常驻。

## 2. 产品原则

### 2.1 指标优先

- 用户记录一次财务事件，所有关联指标从同一条记录计算。
- 派生指标不能通过手工记录重复增加。
- 每个指标、图表、报告结论和预警都能追溯到原始记录。

### 2.2 成本与现金流分离

- 固定成本和可变成本表示已经发生的消耗。
- 现金流出表示实际支付出去的钱。
- 固定资产购置属于现金流出，但默认不属于当期成本。
- 偿还应付账款属于现金流出，但不能再次增加成本。

### 2.3 本地数据归用户

- 财务数据只保存在用户电脑。
- EXE 不包含用户账本。
- 备份可复制到另一台电脑恢复。
- 删除、恢复和升级前优先创建可恢复快照。
- LedgerX 不上传交易、余额、报告、预警或使用数据。

### 2.4 报告与预警可信

- 报告只陈述有数据支持的结果。
- 数据不足、分母为零、周期未结束时必须明确提示。
- 预警阈值由用户决定，模板不得未经确认自动启用。
- 预警只提醒条件已满足，不替用户执行任何财务操作。

## 3. 信息架构

### 3.1 主导航

| 页面 | 主要职责 |
| --- | --- |
| 财务总览 | 当前核心指标、最高等级预警、可视化摘要和最近记录 |
| 指标中心 | 启用、隐藏、创建和管理指标 |
| 全部记录 | 搜索、筛选、新增、编辑、删除和恢复记录 |
| 报告与分析 | 日报、周报、月报、年报的可视化查看、周期比较和记录下钻 |
| 预警中心 | 活跃预警、历史事件和规则管理 |
| 设置 | 数据与备份、外观与皮肤、通知、诊断日志和关于 |

“设置”固定在导航底部，不与高频财务功能争夺注意力。数据状态、备份恢复、清空账本、皮肤、自定义 CSS、通知偏好、诊断和日志统一收进设置。首页不展示运行日志、版本日志、数据文件状态或诊断入口；只有账本损坏、WebView2 无法加载等阻断使用的故障，才进入独立恢复或错误页面。

### 3.2 设置页结构

设置页按以下分组组织：

1. 常规与显示：金额隐私、日期和显示偏好。
2. 数据与备份：数据状态、备份、恢复、清空账本、恢复出厂和打开数据目录。
3. 外观与皮肤：内置皮肤、自定义 CSS 和字体显示。
4. 通知与预警：Windows 通知权限、通知金额隐私和提醒偏好；预警规则本身仍在预警中心管理。
5. 诊断与日志：数据完整性、WebView2 状态、日志查看和导出。
6. 关于：版本、开源许可和项目链接。

### 3.3 报告页结构

报告与分析页本身就是可视化报表工作区，默认展示图表视图，并采用统一结构：

1. 报告类型：日报、周报、月报、年报。
2. 周期选择：日期、自然周、月份或年份。
3. 对比周期：上一日、上一周、上月、去年同期或关闭比较。
4. 视图切换：图表视图、数据表视图。
5. 核心指标条。
6. 主趋势或现金变化图。
7. 成本结构和收入结构图。
8. 风险指标与本周期预警。
9. 自动摘要。
10. 原始记录明细与查看数据表。

### 3.4 指标详情页结构

点击财务总览或指标中心的任意指标卡主体，进入该指标的详情页，而不是直接打开新增记录。指标详情页包含：

1. 指标名称、当前值、统计周期、对比值和金额隐藏开关。
2. 指标趋势或结构图；数据不足时降级为 KPI 或数据表。
3. 指标定义、计算公式、时间口径和数据充足性说明。
4. “构成此指标的记录”列表，默认按日期倒序，并支持周期、类型和关键字筛选。
5. 每条记录对指标的贡献方向、贡献值和计算说明。
6. 可记录指标提供独立的“添加记录”按钮；记录行支持查看和编辑。
7. 派生指标展示分子、分母及其来源记录，确保结果可以解释和复核。

## 4. 核心业务逻辑

### 4.1 单一事实链

所有功能遵循以下数据链：

用户新增或修改记录
→ RecordService 校验并保存
→ MetricEngine 重算关联指标
→ ReportEngine 生成当前周期报告
→ WarningEngine 重新评估相关规则
→ C# 生成统一 Snapshot
→ React 更新页面

React 不独立计算正式财务结果。浏览器开发模式可以使用 Mock，但 Mock 必须遵循与 C# 相同的数据契约和测试样例。

### 4.2 记录事件影响

| 事件 | 成本 | 现金流 | 现金储备 | 固定资产 | 应付账款 | 总资产 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 外部收入 A | 不变 | +A | +A | 不变 | 不变 | +A |
| 立即支付固定成本 A | +A | -A | -A | 不变 | 不变 | -A |
| 立即支付可变成本 A | +A | -A | -A | 不变 | 不变 | -A |
| 现金购置固定资产 A | 不变 | -A | -A | +A | 不变 | 不变 |
| 新增应付账款 A | 不变 | 不变 | 不变 | 不变 | +A | 不变 |
| 支付应付账款 A | 不重复增加 | -A | -A | 不变 | -A | -A |
| 自定义指标增加 A | 由指标定义 | 不影响 | 不影响 | 不影响 | 不影响 | 不影响 |
| 自定义指标减少 A | 由指标定义 | 不影响 | 不影响 | 不影响 | 不影响 | 不影响 |

说明：

- v2.1 延续 v2.0 现有记录类型，优先完善可靠性和报告能力。
- 新增应付账款在当前模型中只形成负债；未来如支持“未付款成本”，需要建立成本与应付记录的关联，不能通过同一笔金额重复累计。
- 支付应付账款最多减少至零，不允许产生负应付余额。

### 4.3 期间指标与时点指标

期间指标在选定日期范围内汇总：

- 现金流入
- 现金流出
- 净现金流
- 固定成本
- 可变成本
- 总成本
- 非必要成本
- 自主收入

时点指标计算到周期结束日：

- 现金储备
- 固定资产
- 应付账款
- 总资产
- 净资产
- 流动性

风险指标：

- Burn Rate：最近 N 个完整月的平均生活性现金流出，默认 N=3。
- Runway：周期结束日可动用现金 ÷ Burn Rate。
- 财务依赖度：父母支持类收入 ÷ 总收入。
- 收入集中度：最大单一收入来源 ÷ 总收入。
- 自我造血能力：自主收入 ÷ 现金流出。
- 安全垫覆盖率：现金储备 ÷ 用户设置的安全垫目标。

边界规则：

- 分母为零时显示“暂无法计算”，不能显示 0%。
- Burn Rate 没有完整月份样本时显示“样本不足”。
- Runway 在 Burn Rate 为零时显示“暂无消耗”，不显示无限大。
- 周期未结束时显示“截至今天”，对比时使用相同已过天数。

## 5. 功能需求

### 5.1 设置：数据与备份

#### FR-DATA-001 数据状态

“设置 > 数据与备份”必须显示：

- 数据文件位置。
- 当前记录数和回收站记录数。
- 自定义指标数、预警规则数。
- 数据文件大小。
- 最近保存时间、最近备份时间。
- 应用版本、schemaVersion 和备份格式版本。
- 数据完整性状态。
- 打开数据所在文件夹按钮。

#### FR-DATA-002 完整备份

备份文件使用“信封 + 载荷”结构：

- formatVersion
- appVersion
- createdAt
- summary
- checksum
- payload

summary 至少包含记录数、自定义指标数、预警规则数和记录日期范围。checksum 使用 SHA-256 对 payload 计算。

保存流程：

1. 用户选择目标文件。
2. 系统写入临时文件。
3. 系统重新读取并验证格式和校验和。
4. 验证通过后替换最终文件。
5. 页面展示备份时间、路径和内容摘要。

#### FR-DATA-003 恢复预览

选择备份后必须先只读解析，展示：

- 创建时间和应用版本。
- 记录数、自定义指标数和预警规则数。
- 最早及最晚记录日期。
- 格式兼容性和校验状态。
- 将覆盖当前账本的明确提示。

用户确认前不得修改当前账本。

#### FR-DATA-004 原子恢复

恢复前自动保存当前账本快照。新账本验证成功后才能原子替换主文件。失败时：

- 原数据保持不变。
- 展示失败原因。
- 保留用户选择的原始备份文件。
- 不以空账本代替失败结果。

必须兼容 v2.0 直接导出的 LedgerState JSON。

#### FR-DATA-005 清空账本

清空账本删除：

- 全部有效记录。
- 回收站记录。
- 自定义指标及其记录。
- 预警规则和预警历史。

清空账本保留：

- 皮肤。
- 字体及显示偏好。
- 通用应用设置。

流程：

1. 展示将删除和保留的内容。
2. 默认创建清空前快照。
3. 用户输入“清空 LedgerX”。
4. 清空成功后展示结果和撤销入口。

#### FR-DATA-006 恢复出厂

恢复出厂包含清空账本，并重置全部主题和偏好。WebView2 缓存不属于财务数据，可单独清理，不得与账本清空混为同一动作。

### 5.2 记录管理

#### FR-REC-001 新增记录

保持 v2.0 的日期、类型、金额、分类、账户、备注和自定义指标字段。金额必须为正数，方向由记录类型决定。

#### FR-REC-002 编辑记录

所有有效记录均可编辑。保存前展示：

- 原值和新值。
- 受影响指标。
- 指标变化方向和差额。

保存后所有指标、报告和预警立即重算。createdAt 保持不变，updatedAt 更新。

#### FR-REC-003 软删除与撤销

- 删除记录后设置 deletedAt，不立即永久移除。
- 删除后提供短时撤销入口。
- 回收站默认保留 30 天。
- 用户可以恢复或永久删除回收站记录。
- 指标、报告和预警只读取未删除记录。

#### FR-REC-004 搜索与筛选

支持：

- 日期范围。
- 记录类型。
- 分类。
- 收入来源。
- 账户。
- 金额范围。
- 备注关键字。
- 有效或已删除状态。

#### FR-REC-005 收入来源

收入增加结构化字段 incomeSource：

- 父母支持
- 奖学金
- 兼职
- 实习或工资
- 投资收益
- 退款
- 其他

并增加 isSelfGeneratedIncome。财务依赖度和自我造血能力必须读取结构化字段，不再依赖分类文字匹配。旧记录允许保留未知状态，并支持批量补充。

### 5.3 指标与统计周期

#### FR-METRIC-001 周期选择

总览和报告支持：

- 今天
- 本周，周一至周日
- 本月
- 上月
- 本年
- 全部
- 自定义日期范围

#### FR-METRIC-002 指标口径

每张指标卡显示：

- 指标名称。
- 当前值。
- 统计口径，如“本月累计”或“截至 9 月 9 日”。
- 隐藏或显示金额。
- 是否存在活跃预警。
- 点击卡片主体进入指标详情。
- 对可直接记账的指标，提供与卡片点击分离的“添加记录”快捷按钮。

#### FR-METRIC-003 自定义指标

v2.1 保持手工累计型自定义指标：

- 金额、数值、百分比格式。
- 增加和减少记录。
- 可用于报告 KPI 和预警规则。

自定义公式和指标依赖编辑器不属于 v2.1。

#### FR-METRIC-004 指标详情与数据下钻

所有内置指标和自定义指标都必须可以打开详情页：

- 展示当前值、对比值、统计周期、口径、公式和数据状态。
- 展示该指标在所选周期内的趋势或结构图；数据不足时显示清晰的降级状态。
- 展示“构成此指标的记录”，并支持日期范围、记录类型和关键字筛选。
- 自定义指标展示该指标的全部增加和减少记录。
- 现金流、成本、资产和应付账款等指标展示对结果有贡献的原始记录及正负方向。
- Runway、财务依赖度等派生指标展示分子、分母、计算过程及各自来源记录。
- 可直接记账的指标提供“添加记录”；点击已有记录可以进入编辑。
- 软删除或恢复记录后，详情值、图表和记录列表必须同步更新。
- 明细贡献合计必须与当前指标值或其期间变动一致；无法直接相加的比率指标必须给出可复核的计算说明。

### 5.4 日报、周报、月报和年报

#### FR-REPORT-001 共同结构

四类报告必须：

- 使用同一个 MetricEngine 和 ReportEngine。
- 显示周期、生成时间、单位和口径。
- 支持隐私模式。
- 支持查看数据表和下钻记录。
- 在记录新增、编辑、删除或恢复后实时更新。
- 区分无数据、数据不足和真实零值。

#### FR-REPORT-002 日报

日报回答“今天发生了什么”：

- 当日现金流入、现金流出、净现金流。
- 期初和期末现金。
- 固定成本、可变成本、固定资产购置。
- 新增和支付的应付账款。
- 主要分类、最大单笔变化和记录明细。
- 与昨日的同口径比较。

#### FR-REPORT-003 周报

周报默认周一至周日：

- 本周流入、流出、净现金流和上周对比。
- 固定成本、可变成本、非必要成本。
- 周初和周末现金变化。
- 七天每日净现金流。
- 成本分类 Top 5。
- 未来七天已知应付款提示。

当前周未结束时，只和上周相同已过天数比较。

#### FR-REPORT-004 月报

月报包含：

- 月度流入、流出、净现金流及环比。
- 固定成本、可变成本和成本结构。
- 收入来源、财务依赖度和自主收入占比。
- 月初与月末现金、固定资产、应付账款和总资产变化。
- Burn Rate、Runway 和安全垫状态。
- 本月主要变化、异常大额记录和自动摘要。

#### FR-REPORT-005 年报

年报包含：

- 全年流入、流出、成本和净现金流。
- 十二个月趋势及最高、最低月份。
- 年初与年末现金、固定资产、应付账款和总资产变化。
- 收入集中度、财务依赖度和自我造血能力。
- 固定成本和可变成本年度结构。
- 年度主要财务事件和自动摘要。

### 5.5 可视化报表

#### FR-CHART-001 图表地图

| 报告 | 分析问题 | 图表 |
| --- | --- | --- |
| 日报 | 今日现金为何变化 | 期初 + 流入 - 流出 = 期末的瀑布图 |
| 日报 | 最近是否异常 | 最近 14 天净现金流柱形图 |
| 周报 | 一周节奏如何 | 周一至周日净现金流柱形图 |
| 周报 | 与上周差异 | 本周与上周分组条形图 |
| 月报 | 月内变化 | 每日流入、流出和净现金流折线图 |
| 月报 | 成本结构 | 固定成本与可变成本堆叠条形图 |
| 月报 | 主要影响分类 | Top 5 水平条形图 |
| 年报 | 全年趋势 | 十二个月现金流折线图 |
| 年报 | 成本结构变化 | 月度固定与可变成本堆叠柱形图 |
| 年报 | 收入集中度 | 收入来源排序条形图 |
| 年报 | 资产与负债演变 | 月末时点指标趋势图 |

#### FR-CHART-002 数据充足性

- 时间趋势少于 8 个有效点时降级为柱形图、KPI 或数据表。
- 分类少于 4 个时使用紧凑排行。
- 分类超过 5 个时显示 Top 5 + 其他。
- 分母为零时不绘制百分比。
- 未来日期留空，不当作零。

#### FR-CHART-003 视觉规则

- KPI 用于精确状态，图表用于趋势、比较和结构。
- 金额柱形图从零开始。
- 单图最多使用暖铜主色、一个辅助色和中性色。
- 不只依赖红绿颜色表达正负。
- 使用正负号、零线、明暗、线型或实心/空心标记。
- 标题客观描述指标，副标题显示周期、单位和数据粒度。
- 皮肤切换后图表同步读取 LedgerX CSS 变量。

#### FR-CHART-004 交互

- 鼠标悬停和键盘聚焦显示日期、金额、占比和比较值。
- 点击数据点或分类下钻到筛选后的记录。
- 可隐藏系列，但不能改变其他系列的计算口径。
- 提供查看数据表入口。
- 返回报告时保留周期和滚动位置。

#### FR-CHART-005 隐私

金额隐藏后，KPI、坐标轴、标签、提示框、数据表、导出内容和无障碍文本均不得泄露具体金额。

#### FR-CHART-006 技术

- 使用本地 npm 图表依赖，建议 Recharts。
- 禁止 CDN、远程字体和远程数据源。
- 图表数据由 C# ReportEngine 输出，React 只渲染和交互。

#### FR-CHART-007 财务总览可视化摘要

财务总览必须加入一个轻量可视化摘要：

- 默认展示当前所选周期的现金流入、现金流出和净现金流趋势。
- 图表随总览周期选择和金额隐私模式同步变化。
- 点击图表或“查看完整报告”进入报告与分析，并保留当前周期。
- 首页只保留一个主图表，避免把总览堆成报表墙；完整结构、对比和下钻在报告与分析中完成。
- 首页不得混入运行日志、诊断信息或数据文件状态。

### 5.6 财务预警

#### FR-WARN-001 规则字段

每条规则包括：

- id、名称、说明、启用状态。
- 监控指标。
- 统计周期。
- 比较方式。
- 阈值和单位。
- 可选比较基准。
- 连续周期数。
- 严重程度。
- 重复与冷却策略。
- 生效和失效日期。
- 通知方式。
- 是否允许显示金额。

#### FR-WARN-002 支持条件

支持：

- 大于、大于等于。
- 小于、小于等于。
- 等于。
- 相对上一周期变化超过。
- 相对最近 N 期平均值变化超过。
- 连续 N 个周期为正或为负。
- 多个条件全部满足的 AND 组合。

不支持嵌套 AND/OR 规则树。

#### FR-WARN-003 规则创建

1. 选择指标。
2. 选择周期。
3. 选择比较方式。
4. 输入阈值或比较基准。
5. 设置连续周期、严重程度和冷却时间。
6. 使用当前账本预览是否会立即触发。
7. 确认并启用。

保存前显示自然语言摘要，例如：“当本月可变成本大于 ¥2,000 时，产生关注级预警，每月最多提醒一次。”

#### FR-WARN-004 预警状态

预警事件状态：

- 活跃
- 已读
- 已暂停
- 已解决
- 已忽略

同一规则在冷却期内不得重复创建相同事件。记录被编辑、删除、恢复或周期变化后重新评估；条件不再满足时自动解决。

#### FR-WARN-005 预警中心

预警中心包含：

- 活跃预警。
- 未读数量。
- 按严重程度、指标、状态和日期筛选。
- 已解决和已忽略历史。
- 规则列表及新建、编辑、暂停、复制和删除。

总览只显示最高等级的少量活跃预警。指标卡和周期报告显示相关预警标记。

#### FR-WARN-006 可解释性

每次预警显示：

- 当前值。
- 阈值。
- 统计周期。
- 触发时间。
- 计算公式。
- 关联记录。

数据不足时状态为“暂无法评估”，不能按零触发。

#### FR-WARN-007 示例模板

模板仅供用户选择启用：

- 现金储备低于 ¥3,000。
- Runway 少于 2 个月。
- 本月可变成本超过 ¥2,000。
- 非必要成本占比超过 25%。
- 财务依赖度连续两个月超过 60%。
- 本周现金流出超过最近四周平均值的 130%。
- 未来七天应付款超过现金储备的 30%。
- 净现金流连续两个月为负。

#### FR-WARN-008 评估时机

WarningEngine 在以下时机执行：

- 应用启动。
- 新增、编辑、删除或恢复记录。
- 添加、编辑或删除指标。
- 新增、编辑、启用或暂停规则。
- 恢复备份。
- 用户切换报告周期。

v2.1 的核心是应用内预警。Windows 本地通知属于建议交付项，不能阻塞预警中心发布。

### 5.7 设置、异常与诊断

#### FR-SET-001 设置中心

设置页统一承载低频配置和维护功能：

- 常规与显示。
- 数据与备份。
- 外观与皮肤。
- 通知与预警偏好。
- 诊断与日志。
- 关于。

数据管理和外观皮肤不再作为一级主导航页面。进入设置后保留当前设置分组，返回业务页面时保留原页面状态。

#### FR-SET-002 首页信息边界

财务总览只展示财务决策相关内容：核心指标、一个可视化摘要、最高等级预警和最近记录。运行日志、版本日志、WebView2 状态、数据路径、文件大小和完整性诊断不得作为首页卡片出现。

阻断应用正常使用的故障不受此限制，应进入独立的恢复或错误页面，并提供前往“设置 > 诊断与日志”的入口。

#### FR-DIAG-001 损坏账本

账本无法解析时：

- 保留损坏文件副本。
- 展示专门恢复页面。
- 显示损坏副本和可用备份位置。
- 允许打开数据目录、恢复备份或创建空账本。
- 不直接静默进入空账本。

#### FR-DIAG-002 WebView2

WebView2 Runtime 缺失时展示明确安装说明。Web 静态资源缺失时展示本地资源错误和诊断入口，不显示空白窗口。

#### FR-DIAG-003 日志

日志仅在“设置 > 诊断与日志”中查看或导出，不在财务总览展示。日志可以记录版本、错误类型、堆栈和操作名称，但不得记录金额、分类、账户、备注和完整账本内容。

## 8. 状态流转

### 8.1 记录

有效 → 软删除 → 恢复为有效

有效 → 软删除 → 永久删除

编辑记录保持同一 id，更新 updatedAt。

### 8.2 恢复备份

选择文件 → 只读解析 → 校验 → 展示预览 → 用户确认 → 创建保护快照 → 原子替换 → 重算指标 → 重算报告 → 重算预警 → 完成

任何步骤失败均回到原账本状态。

### 8.3 预警

规则启用 → 暂无法评估或未触发 → 活跃 → 已读或已暂停 → 已解决

用户忽略只关闭当前事件，不自动关闭规则。

## 10. 非功能要求

### 10.1 性能

- 1,000 条记录下，总览、报告切换和保存记录的可感知等待不超过 300ms。
- 10,000 条记录下，常用报告生成不超过 1 秒。
- 只重算受影响指标、报告和预警；首版可全量重算，但必须满足性能指标。

### 10.2 数据安全

- 所有写入使用临时文件和原子替换。
- 恢复、清空和结构升级前创建保护快照。
- 备份恢复必须校验格式和 checksum。
- 未识别的未来 schemaVersion 拒绝覆盖当前账本。

### 10.3 隐私

- 不上传数据。
- 金额隐藏覆盖 KPI、表格、图表、提示框、预警、通知和导出。
- 日志不包含财务明细。

### 10.4 可访问性

- 支持键盘完成全部核心流程。
- Escape 可以安全关闭弹窗。
- 图表提供数据表替代视图。
- 不依赖颜色表达唯一含义。
- 支持 Windows 100%、125%、150% 和 200% 缩放。

### 10.5 兼容性

- Windows 10/11 x64。
- 使用系统 WebView2 Runtime。
- v2.0 ledger.json 和 v2.0 JSON 备份可以无损迁移。
- 自定义 CSS 继续只允许安全的 lx 变量。

## 11. 验收标准

### 11.1 数据生命周期

- 可以查看账本状态和文件位置。
- 可以创建带版本、摘要和 checksum 的备份。
- 恢复前可以查看备份内容。
- 恢复失败不会修改当前账本。
- 可以清空账本和恢复出厂。
- 所有危险操作默认创建保护快照。

### 11.2 记录与指标

- 任意记录可编辑、软删除、撤销和恢复。
- 编辑收入后现金、净现金流和总资产正确更新。
- 固定资产购置不计入固定或可变成本。
- 偿还应付账款不重复增加成本。
- 期间指标和时点指标在跨日、周、月、年时口径正确。
- 点击任意指标卡可以进入指标详情，并查看构成该指标的已添加记录。
- 指标详情中的记录贡献合计与指标值或期间变动一致。
- 自定义指标的增加和减少记录可以在详情中完整查看、筛选和编辑。

### 11.3 报告

- 日报、周报、月报和年报均默认提供可视化图表，并可切换周期。
- 财务总览显示一个轻量可视化摘要，点击后可进入同周期完整报告。
- 当前未结束周期使用同进度比较。
- 每个数字和图表可下钻到原始记录。
- 无数据、样本不足和分母为零有不同状态。
- 隐私模式不会通过图表或数据表泄露金额。

### 11.4 预警

- 用户可以新建、预览、编辑、暂停、复制和删除规则。
- 支持单条件及 AND 组合。
- 阈值边界、连续周期和冷却时间计算正确。
- 数据不足不误报。
- 记录变化后预警能重新评估和自动解决。
- 每次预警可解释当前值、阈值、周期、公式和记录来源。

### 11.5 设置与诊断

- 数据、皮肤、通知、诊断日志和关于按分组统一收进设置。
- 财务总览不出现日志、数据路径、文件大小或 WebView2 诊断卡片。
- 阻断性故障通过独立错误页处理，并能进入诊断位置。

### 11.6 发布质量

- C# 单元测试通过。
- 数据迁移和备份恢复集成测试通过。
- React 构建和类型检查通过。
- Playwright 核心流程、响应式和控制台检查通过。
- 最终单文件 EXE 实际启动验证，不只验证浏览器 Mock。
- 桌面快捷方式和应用内图标一致。

### 13.4 设置与导航

- 日志、数据路径、文件大小和 WebView2 状态只出现在设置或独立故障页。
- 设置分组切换、返回状态和键盘导航。
- 从总览图表进入报告时保留统计周期。
- 从指标卡进入详情、从详情添加或编辑记录后返回状态正确。

### 13.5 预警

- 等于阈值的边界。
- 连续周期中间被打断。
- 冷却期内重复计算。
- 修改、删除和恢复触发预警的记录。
- 自定义指标被删除时的依赖提示。
- 数据不足、分母为零和旧记录收入来源未知。

## 14. 完成定义

v2.1 只有同时满足以下条件才可以发布：

1. 用户无需打开资源管理器即可迁移、恢复、清空和定位数据。
2. v2.0 数据和备份可以无损升级。
3. 记录可编辑、撤销删除并恢复。
4. 指标具有明确周期和一致口径，并能点进详情查看已添加的数据和计算依据。
5. 财务总览提供轻量可视化，日报、周报、月报和年报可查看、比较、可视化和下钻。
6. 用户可以为任意可计算指标建立自己的预警。
7. 报告和预警中的每个数字都有计算依据。
8. 数据、外观、通知和诊断日志统一收进设置，首页不展示日志；数据损坏和 WebView2 故障不会表现为空白应用。
9. 自动化测试与最终 EXE 验收全部通过。

一句话定义：v2.1 不只是告诉用户“钱还剩多少”，还要让用户能安全带走账本、看懂变化，并在自己设定的风险线被触碰时及时知道。
