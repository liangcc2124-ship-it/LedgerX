先运行 `scripts/build-web.ps1` 构建网页和 Java 服务，再运行 `scripts/start-local.ps1`。首次使用需在 `frontend/` 执行 `npm ci`。普通使用只需启动 Java 服务，不需要 Node、Vite 或 Electron。
